## Remaining gaps

### 1. Raw-pointer operators (~15 errors)
`*mut T` and `*const T` need `impl Add<usize>` and inherent methods
`add`/`sub`/`is_null`/`addr`. Handwritten impls in `ptr.g` failed
(Script 81 → 82) because `as` cast between `*mut T` and `usize` doesn't
compose with method dispatch.

**Fix direction**: implement raw-pointer `Add` and method lookup in the
compiler (`resolve_method_call` should special-case `TyKind::RawPtr` with
a hardcoded method table), not in stdlib source.

### 2. `len` ambiguity (~30 errors, all downstream)
`impl str { fn len }` and `impl<T> [T] { fn len }` both match `&str`
receivers. Script 79-80's filter should reject `[T]` but the diagnostic
shows both candidates printing as `str`.

**Fix direction**: dump `candidates` in `resolve_method_call` for a `&str`
receiver to see what `self_ty` each candidate carries.

### 3. `I::Item` residuals (2)
Scripts 62-75 cleared 6 of 8. The last 2 are a different impl shape
(likely `impl<I> SomeTrait for X<I>` with the bound on the impl).

**Fix direction**: dump the exact source lines producing the 2 errors.

### 4. Coherence conflict (`trait #87`, 1)

### 5. `U` / `U::Error` (1)
